SYSTEM ARCHITECTURE

測定ロジックの科学的根拠

CORE ANALYZERは、プロフェッショナルに必要な「実践的な認知能力」を6つの次元から正確にプロファイリングするために設計されています。

📊 3層構造レーダーチャートについて
ポータル画面のチャートは、あなたの実力（青線）が、一般平均（白点線）と、目標とすべきエリート研究者基準（オレンジ破線）に対してどの位置にあるかを可視化しています。
🧠
KNOWLEDGE / 結晶性知能
知識力
学習や経験によって蓄積された「結晶性知能」を測定します。いかに優れた推論力を持っていても、基盤となる語彙や専門知識が欠けていれば、正しい仮説は構築できません。このテストでは、広範な事象に対する正確な知識のストック量を評価します。
🎯
PROCESSING / スループット
情報処理能力
一定時間内にどれだけの単純作業を正確に反復できるかという「運動・情報処理のスループット」を測定します。研究におけるデータ入力や単純計算など、疲労下においてもペースを落とさずに作業を完遂する「脳のスタミナとクロック周波数」の指標となります。
⚡
ALERTNESS / 覚醒度・反応速度
覚醒反応
突発的な事象に対する視覚的反応速度を測り、現在の「脳の覚醒レベル」をプロファイリングします。睡眠不足や疲労が蓄積しているとこの数値は露骨に低下します。イレギュラーなデータに対して、フライング（誤検知）することなく確実に対応するための「神経伝達の最適化」を評価します。
💡 評価ポイント：疲労度を測るコンディション・バロメーター
⏱️
TIME PERCEPTION / 内的リズム
時間知覚
外部からの情報を遮断された状態で時間を正確に見積もる「体内時計（インターナル・クロック）」の精度を測定します。人間は焦っていたり、逆に集中しすぎていると脳内の時間にズレが生じます。この誤差を測ることで、現在のあなたの「精神的な焦燥感・落ち着き」を分析します。
🔍
OBSERVATION / ノイズフィルタリング
異常検知
膨大な類似データの中から、わずかな「外れ値」を瞬時に見つけ出す「パターン認識能力」を測定します。ゲシュタルト崩壊に耐えながら、マクロな全体像とミクロな差異を素早く切り替える視覚探索機能は、データの有意差を見抜くために不可欠です。
🧩
LOGIC / 命題処理・流動性知能
論理処理
プログラミングやデータ検索の基盤となる「ブール論理（AND / OR / NOT）」を、脳内でいかに高速かつ正確に演算できるかを測定します。また、ルールが突然切り替わる状況下で適応する「認知的柔軟性（ウィスコンシン・カード分類テストの応用）」も同時に評価します。
💡 評価ポイント：複雑な命題を瞬時に理解し仕分ける実務的処理速度
🖼️
REWARD SYSTEM / 解析ポイント
データ・アーカイブとAP
各テストを実行し、自己ベストを更新したり毎日のシステム起動（デイリーボーナス）を行うことで、「解析ポイント（AP）」が蓄積されます。

獲得したAPを消費することで、量子暗号化された200種類の背景データを復号（ガチャ）することが可能です。復元に成功したデータは、ポータルのメインモニター（背景）に固定することができます。
